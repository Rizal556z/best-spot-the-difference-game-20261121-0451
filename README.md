**Lantern Hunt** — an original spot-the-difference game in the browser. Two near-identical pictures hang side by side; find every hidden change before the lanterns burn down. Three hand-drawn procedural scenes — a lantern-lit night market, a koi garden at dusk, and a clockmaker's workshop — with 5, 6 and 7 differences each (18 in all), gold ring markers on every find, a counter of how many remain, a timer, score with combo bonuses, hints, wrong-click penalties, synthesized WebAudio sounds, and keyboard play (arrow-key reticle + Enter) alongside the mouse. All art, sounds and names are original, drawn in code with canvas 2D — no image or audio files, no network requests, fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a difference in either picture to ring it, or move the reticle with the arrow keys and press Enter. H for a hint, P to pause, M to mute, R to restart.
